# Custos fixos

- Despesas que se repetem todo mês (aluguel, internet, academia). Podem sair de uma conta ou de um cartão.
- Ativo numa competência se a vigência cruza o mês (mesma regra das receitas).
- **Pago no mês** quando existe uma despesa paga na mesma competência, mesma categoria e mesmo valor. Cada lançamento confirma no máximo um custo, para não contar duas vezes.
- Custo fixo em cartão compõe a fatura; não gera uma segunda saída na conta.
