# Contas

- Tipos: corrente, poupança, investimento, carteira.
- **Saldo atual** = saldo inicial + receitas pagas − despesas pagas ± transferências (ver `lancamento/RULES.md`). Pendentes e cancelados não mexem no saldo.
- Só uma conta é a **principal**. A primeira conta criada vira principal automaticamente.
- Conta arquivada continua com histórico, mas sai do saldo total do painel.
